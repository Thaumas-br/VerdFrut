## 📖 Sobre o Projeto

A **VerdFrut** é um comércio de frutas, verduras e legumes. Este projeto é uma aplicação web que apresenta os produtos da empresa, destaca ofertas e permite ao cliente finalizar um pedido por uma página de checkout, aplicando conceitos de desenvolvimento front-end e trabalho em equipe.

## 🎯 Objetivos

- Desenvolver uma aplicação web para um comércio específico.
- Aplicar na prática HTML, CSS e JavaScript.
- Exercitar o versionamento e a colaboração com Git e GitHub.

## ✨ Funcionalidades

- Página inicial com catálogo de produtos
- Banner de ofertas em destaque
- Página de checkout para finalização do pedido
- Carrinho, validação de formulário, layout responsivo

## 💻 Como Executar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/Thaumas-br/VerdFrut.git
   ```
2. **Acesse a pasta do projeto:**
   ```bash
   cd VerdFrut
   ```
3. **Abra no navegador:**
   - Dê dois cliques em `index.html`, **ou**
   - Use a extensão **Live Server** do VS Code (clique direito em `index.html` → *Open with Live Server*).

> Não precisa instalar nada: o projeto roda direto no navegador.
